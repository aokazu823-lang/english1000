英単語1000問チャレンジ v1.0

【PC用】
index.html
GitHub Pages公開後は、リポジトリのトップURLをPCで開きます。
PC単体でもテスト作成・印刷・採点・進捗管理ができます。

【iPad用（任意）】
ipad.html
GitHub Pages公開後は、トップURLの末尾に /ipad.html を付けて開きます。
PC画面に表示された6桁の接続コードを入力してください。
※iPad連携にはPC・iPad双方のインターネット接続が必要です。
※iPadが接続できなくても、PC単体で運営できます。

【保存について】
参加者や進捗は、使用したPCのブラウザ内に保存されます。
本番前・終了後には、設定画面からバックアップを書き出してください。
