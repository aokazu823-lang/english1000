・問題＋解答はA4で別ページになるよう改ページを強化
・解答用紙の文字を少し大きく調整
・START／次の50問／再テスト作成後に印刷選択画面を表示

【GitHub更新方法】
リポジトリ直下の index.html と ipad.html を、このフォルダ内の同名ファイルで置き換えてください。
README.txtも必要に応じて置き換えられます。

【注意】
既存の参加者・進捗データはブラウザ内に保存されているため、index.htmlを差し替えても通常は残ります。念のため、更新前に「保存・設定」からバックアップを書き出してください。
